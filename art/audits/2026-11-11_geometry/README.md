# 1시즌 모델 단계·정점 감축 검토 — 2026-11-11

사용자가 채택한 통합 마을의 단계 모델 존재 여부와 추가 경량화 여지를 확인했다. 제작 원본·기존 GLB·앱 파일은 변경하지 않았다. 이 폴더의 GLB는 검토용 3단계 후보이며 아직 납품본 교체용이 아니다.

## 단계 파일 확인

`town_season1_v002_integrated/reports/manifest.json`이 참조하는 **12종 × 3단계 = 36 GLB**의 존재와 SHA-256을 실제 파일에서 확인했다. 지도는 주택을 세 곳에서 재사용해 총 14채다. 정규화한 8종의 24개는 v002, 성당·여관·방앗간·농가의 12개는 v001 참조다.

원시 GLB에서 정점·인덱스·색·노멀과 면 수를 읽었다. 전체 36개에서 모든 속성이 같은 중복 정점은 21개, 미사용 정점은 0개다. 위치가 같아도 노멀·색이 다른 정점은 모서리와 색 경계를 위한 것이므로 무조건 합치지 않는다. [파일별 실측](inventory.json).

| 14채를 해당 단계로 표시할 때 | 삼각형 | GLB 정점 합계 |
| --- | ---: | ---: |
| 모두 1단계 | 31,576 | 41,911 |
| 모두 2단계 | 53,054 | 69,812 |
| 모두 3단계 | 70,248 | 92,375 |

정점 합계는 실제 인스턴스 수를 반영하며 같은 주택의 재사용도 합산했다. 자산의 메모리 공유나 GPU 드로 호출 수를 뜻하지 않는다. 실제 저장된 최종 Blender 장면은 활성 인스턴스를 평가했을 때 총 108,035 triangles다. 그중 지형·소품 등은 37,787 triangles이며 연속 지형 하나가 26,400개다. 원본 라이브러리와 비활성 편집 장면은 합계에서 제외했다.

## 내부에 가려진 면 제거 실험

편집 원본의 각 구성 부품을 평가하고, 모든 정점이 각 바깥쪽 면의 뒤에 있는 닫힌 볼록 부품을 가림체로 사용했다. 최종 GLB 삼각형의 세 꼭짓점이 가림체 내부에 0.05mm 이상 들어간 경우만 제거했다. 불투명 부품의 내부에 완전히 들어간 삼각형이 대상이다. 남은 POSITION/NORMAL/COLOR_0 등 정점 속성은 원래 바이트 그대로 복사하고 인덱스·사용 정점만 다시 구성했다.

| 최종 14채 L3 | 원본 | 내부 면 제거 시험본 | 감소 |
| --- | ---: | ---: | ---: |
| 삼각형 | 70,248 | 59,214 | 15.7% |
| 내보낸 정점 | 92,375 | 80,042 | 13.4% |

성당의 삼각형은 6,730 → 4,468, 정점은 10,093 → 6,895로 줄었다. [유형별 수치와 가림 부품](hidden_faces.json). 후보 12개 모두 다시 가져와 정점색·정상 노멀·퇴화 삼각형 0을 확인했다.

- [원본 마을](01_original.png)
- [원본 GLB 재가져오기 대조군](01b_original_glbs_reimported.png)
- [내부 면만 제거한 마을](02_hidden_faces_removed.png)

같은 카메라·조명·1440×900·Cycles 64 samples에서 실제 이미지를 열어 비교했다. 이 전체 시점에서는 실루엣이나 색의 큰 변화를 보지 못했다. 원본 GLB 재가져오기 대조군 대비 선형 RGB 평균 절대 차이는 약 0.0000195이며, 채널 차이가 0.01을 넘는 픽셀은 약 0.031%였다. 렌더 샘플링 차이가 포함되므로 픽셀 완전 동일을 주장하지 않는다. [재가져오기·이미지 차이 기록](comparison.json).

현재는 **3단계 12종에 한한 실험**이다. 1·2단계 적용, 확대·후면 확인, 모든 단계의 위치·출입구 재검수와 앱 테스트는 다음 적용 작업에서 수행해야 한다. 원본 부품을 편집할 때의 닫힌 솔리드 검사와 내부 면을 제거한 런타임 메시의 검사는 목적이 다르다.

## 다른 감축 후보

- 얇은 상자 부품(두께 6cm 이하)의 bevel만 메모리에서 끈 산술 실험은 최종 건물 삼각형 3,136개, 약 4.5%를 줄였다. 이 안의 외관은 별도 검수하지 않았다. 내부 면 제거와 중복되는 면이 있으므로 두 감소량을 더하지 않는다. [부품별 비용](component_profile.json).
- 지형 Decimate 25%는 26,400 → 6,600 triangles로 줄었다. 하지만 원본과 같은 XY의 수직 교차 높이를 39,600곳에서 비교했을 때 최대 약 0.281m, 99백분위 약 0.0142m 차이가 발생했다. 기존 경계 샘플 231곳은 원본 자체의 교차 실패로 비교에서 제외했다. 이 자동 감축안은 **그대로 적용하지 않는다.** 길·건물 주변 정점을 보존하는 별도 방식과 접지 확인이 필요하다. [시각 시험](03_hidden_faces_and_quarter_terrain.png).

권장 순서는 내부 면 제거를 전 단계로 확장·검수하는 것이다. 지형은 길·기초·강둑을 보존하는 방식으로 후속 검토한다. 현재 원본을 자동 교체하지 않았으며 Android/Pleos/실차 프레임 속도·메모리·발열은 측정하지 않았다.

## 재현 파일

- `audit_glbs.py`: 36개 원본 GLB 읽기·단계/해시/속성 확인.
- `profile_blend.py`: 편집 부품·활성 장면 비용과 메모리 내 얇은 bevel 실험.
- `hidden_faces.py`: 검토용 L3 후보를 이 폴더에만 생성.
- `compare_candidates.py`: 후보 재가져오기·같은 조건 렌더·지형 높이 비교. 기존 동일 이름의 감사 렌더는 재사용하므로 입력·방법을 바꾸면 새 감사 폴더에서 실행한다.

Blender 스크립트는 background와 `--python-exit-code 1`로 실행했다. 원본 `.blend`와 GLB 해시를 다시 확인했으며 제작 원본을 저장하거나 기존 생성 드라이버를 실행하지 않았다.
