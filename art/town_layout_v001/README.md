# 고정 마을 첫 배치 v001 — 채택하지 않음

2026-11-09 사용자 검토에서 너무 규칙적이고 신도시 같으며 게임 속 마을처럼 보이지 않는다는 피드백으로 거절된 배치다. 전체 마을의 채택 기준이나 후속 확장 템플릿으로 사용하지 않는다. 기존 건물 원본과 이 시안은 비교를 위해 보존한다.

- [첫 배열](reports/iteration_01_mature.png): 두 줄 건물과 외곽 순환로.
- [두 번째 프리뷰](renders/preview_town_mature.png): 각도와 간격, 중앙 분수 시야를 수정했으나 전체 구성 문제를 해결하지 못했다.
- [후속 레퍼런스와 수정 기준](../reference/town_layout_2026_11_09/README.md).

파일은 오프라인 조립 시안이다. 최종 납품·사용자 미감 승인·Android 연결·차량 성능 검증이 완료되지 않았다. 두 번째 프리뷰는 협업 세션의 GLB 수정과 동시에 실행되어 마지막 입력 해시 검사가 실패했다. `verify_town.py`는 작성했지만 최종 조립 검증은 실행하지 않았다. 현재 .blend/GLB를 검증 완료 자산으로 취급하지 않는다.
