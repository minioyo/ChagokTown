## 앱에서 사용할 때

- 실제 GLB를 로드한다. 미리 렌더한 PNG나 카드로 모델 표시를 대체하지 않는다.
- glTF의 장면 노드 변환과 +Y up을 따른다. Blender 원본은 +Z up이지만 별도의 임의 축 회전을 중복 적용하지 않는다.
- 단위는 m이며 바닥 기준점은 모델의 루트다. 모든 모델을 동일한 단위 큐브나 같은 높이로 정규화하면 성당·집 비례가 깨진다. 임시 배치 데이터와 카메라에서 각 최대 크기를 고려한다.
- 색은 `COLOR_0` 정점색이다. 외부 텍스처는 없으며 정점색을 무시하면 흰 모델이 된다. 정상 노멀과 불투명 재질·뒷면 컬링을 반영한다.
- 단계 교체 시 부지 위치와 모델 루트를 유지한다. 최종 맵/비례 모델은 나중에 경로·배치 데이터를 교체할 수 있게 연결하되 범용 에셋 프레임워크를 추가하지 않는다.
- `manifest.json`은 전달용 메타데이터다. 앱의 카탈로그 스키마와 저장 ID는 개발 세션이 기존 코드·마이그레이션을 확인하고 정한다.
- 기존 저장 데이터, 자원 차감·건설/강화의 트랜잭션, 주행 제한과 앱 백그라운드 전환은 계속 검증한다.

샘플 복사와 GLB 구조 검사는 수행했다. 원본별 Blender 재열기/재가져오기 검증은 manifest에 연결된 기존 보고서에 있다. **이 전달 단계에서 Android 렌더링이나 차량 성능을 검증한 것은 아니다.**

개발 세션은 `android/`와 개발 문서를 담당한다. 모델링 세션은 `art/town_season1_v002_integrated/`를 담당하며 이 샘플과 기존 원본은 수정하지 않는다.
