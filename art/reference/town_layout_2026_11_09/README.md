# 차곡마을 배치 레퍼런스 — 2026-11-09

사용자 피드백: 현재 마을은 너무 규칙적이고 신도시 같으며, 게임 속 마을처럼 보이지 않는다. `town_layout_v001`을 채택하지 않는다. 이 문서는 실제 게임의 공개 이미지를 확인한 공간 구성 분석이다. 새 배치의 사용자 승인을 뜻하지 않는다.

## 사용자가 선택한 최우선 이미지

2026-11-09 사용자가 아래 Tiny Glade 장면을 직접 첨부하며 “지금 sol이 작업하고 잇긴한데 이거 이쁘다 이런느낌을 원햇던거”라고 말했다. [사용자 첨부 원본](user_selected_tiny_glade.png)은 임시 첨부 파일을 변환 없이 보존했고 SHA-256 일치를 확인했다. 아래 공식 배포 이미지 `tiny_glade_village.jpg`와 같은 장면이다. Townscaper/Palia는 보조 참고로 사용한다.

제작 해석: 촘촘한 건물 군집, 겹쳐 보이는 서로 다른 지붕 높이, 좁은 골목에서 열리는 작은 광장, 수로·다리·아치·계단, 중심 랜드마크와 낮은 주변 집, 따뜻한 돌벽·목재와 차분한 지붕색이 함께 만드는 동화 속 구시가지 분위기를 우선한다. 기존 상점 모델의 재배치만으로 이 분위기에 접근하지 못하면 핵심 건물의 실루엣과 큰 색면도 별도 사본에서 조정한다.

이 선호가 성·성당 건설 필수, 모든 기존 에셋 폐기, 정확한 지도 복제, 고밀도 메시나 특정 렌더링 기술 채택을 뜻하지는 않는다. 경량화·문자 간판 제거·갈색 창문 덧판 제거·3단계 업그레이드는 유지한다. 돌·기와의 인상은 큰 형태와 성긴 색 변화로 먼저 확인하며, 심도 흐림을 적용하지 않은 전체 화면에서도 구도와 건물 식별이 성립해야 한다.

## 이전 시안에서 바꿀 것

| 이전 시안 | 새 구도에서 확인할 것 |
| --- | --- |
| 타원 판 위 두 줄 상점 | 지형과 공간에 따라 모인 2~3개 건물 군집 |
| 모든 건물이 독립 전시품처럼 분리됨 | 공통 앞마당·골목·담장으로 연결된 생활 공간 |
| 비슷한 높이·폭·같은 카메라 방향 | 크기 차이와 지붕 윤곽, 길을 향하는 입구 |
| 같은 폭의 외곽 순환로 | 목적지가 있는 골목·짧은 계단·연결로 |
| 외곽에 등간격 나무 | 군집 식생과 트인 공간의 대비 |
| 전체를 균등하게 채움 | 시선이 모이는 곳 하나와 조용한 구역 |

제안하는 첫 구도는 작은 광장 옆 상점 3채, 그 옆 골목과 언덕 위 집, 물가의 공방이다. 기존 건물의 따뜻한 색과 장난감 같은 형태는 재사용하되, 건물 사이 공간을 먼저 설계한다. 현재 8종 목록과 4.8m 검사 사각형을 배치 격자로 강제하지 않는다. 나중에 업그레이드할 최대 외곽과 선택 가능한 화면 영역은 별도로 보장한다.

다음 순서는 전체 구도 두 안을 기존 모델·단순 지형으로 빠르게 비교하고, 실제 축소 화면에서 검토한 뒤 필요한 개별 건물을 개선하는 것이다. 현 단계에서 건물 수를 더 늘리거나 세부 장식을 다듬는 것으로 구도 문제를 해결하지 않는다.
